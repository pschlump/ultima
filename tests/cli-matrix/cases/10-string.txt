# String-group cases (P0 strings): SET, GET, GETDEL, GETEX, GETSET,
# INCR, DECR, INCRBY, DECRBY, INCRBYFLOAT, APPEND, STRLEN, MGET, MSET, MSETNX.
#
# All replies in this group are simple strings, integers, bulk strings, nulls,
# flat arrays or errors — the RESP2/RESP3 rendering is identical (INCRBYFLOAT
# returns a BULK string in both protocols), so no == resp3 blocks are needed.
# TTL/PTTL-bearing cases use `match` so wall-clock skew cannot flake them.
