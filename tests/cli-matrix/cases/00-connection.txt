# Connection-group cases (§6.1): PING, ECHO, HELLO, AUTH, SELECT, RESET.
# QUIT is a runner special (special:quit) because the REPLs intercept the
# literal word "quit".
#
# Case format:
#   == case: <name>            unique, dotted group prefix
#   == type: exact|sorted|match|smatch   (default exact)
#   == targets: all|no-redis|resp2|resp3 (default all)
#   == modes: all|auth-only|noauth-only  (default all)
#   <input lines, one per line, all sent on ONE connection>
#   --
#   <expected output lines (RESP2 class rendering)>
#   == resp3            (optional) expected block for RESP3-class targets
#   --
#   <expected output lines (RESP3 class rendering)>
#   == resp3: skip      (alternative: skip this case on RESP3 targets)
