# List-group cases: LPUSH/RPUSH, LPUSHX/RPUSHX, LPOP/RPOP, LLEN, LRANGE,
# LINDEX, LSET, LINSERT, LREM, LTRIM, RPOPLPUSH, LPOS, LMOVE, and the
# blocking family (BLPOP/BRPOP/BLMPOP/BRPOPLPUSH/BLMOVE) in their
# NON-BLOCKING path only — every blocking call below has data ready, so it
# returns immediately. Never issue one against an empty/missing key set:
# it would hang until the runner's 30 s kill.
# No RESP3 blocks: list replies contain no maps/doubles, so all four
# protocols render identically (validated by the redis3 target).
