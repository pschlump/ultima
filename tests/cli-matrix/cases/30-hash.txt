# Hash-group cases: HSET, HGET, HMSET, HMGET, HGETALL, HDEL, HEXISTS, HLEN,
# HKEYS, HVALS, HINCRBY, HINCRBYFLOAT, HSETNX, HSTRLEN, HRANDFIELD, HSCAN.
#
# Notes:
# - HGETALL returns a MAP on RESP3-class targets -> == resp3 block. A missing
#   key renders as `(empty hash)` on RESP3 vs `(empty array)` on RESP2.
# - HINCRBYFLOAT replies are bulk strings on BOTH protocols (probed 7.2.7).
# - HRANDFIELD ... WITHVALUES is a flat alternating array on RESP2 and an
#   array of 2-element arrays on RESP3 (probed 7.2.7: `1) 1) "f"` / `   2) "v"`).
# - Random-order replies (HRANDFIELD) use `match` with per-line regexes: the
#   numeric index prefixes make plain `sorted` comparison unusable for
#   permuted replies (the sorted line multisets differ).
