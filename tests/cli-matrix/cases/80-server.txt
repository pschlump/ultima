# Server-group cases: DBSIZE, FLUSHDB/FLUSHALL, SAVE/BGSAVE/LASTSAVE/
# BGREWRITEAOF, CONFIG GET/SET, COMMAND, CLIENT.
#
# INFO and CLIENT LIST are deliberately excluded (field sets legitimately
# diverge; the runner covers INFO/CLIENT minimally via specials).
# CLIENT NO-EVICT is excluded: unimplemented in ultima (unknown subcommand).
# CONFIG GET no-such-param renders "(empty array)" on RESP2 and "(empty
# hash)" on RESP3 — both clients agree, so one case covers both.

# BGREWRITEAOF runs first: with appendonly off and no child ever forked,
# both ultima and real redis 7.2.7 deterministically reply "started". Placed
# after a BGSAVE it races the still-active child ("scheduled" on redis).

--
