# Scripting-group cases (M8): EVAL, EVALSHA, EVAL_RO, EVALSHA_RO, SCRIPT.
#
# Every expectation here was probed byte-exact against redis-server 7.2.7
# (the corpus in tests/differential/scripts_m8.go proves the same rows
# reply-identical in Ultima), so all cases validate under -R.
#
# Runner notes:
#   * The runner FLUSHALLs before each case but does NOT SCRIPT FLUSH — the
#     script cache persists across cases (on ultima AND on the -R redis).
#     Cache-sensitive cases start with SCRIPT FLUSH and end clean.
#   * Lua sources use the redis-cli input grammar: double quotes group,
#     single quotes inside are literal, \n inside double quotes is a real
#     newline (multi-line scripts pin the @user_script:N line number).
#   * Divergent dialects (docs/Redis-Errors.md §11) are covered only via
#     'match' regexes that pin the byte-exact shape both engines share
#     (scripting.eval-dialect-errors).
