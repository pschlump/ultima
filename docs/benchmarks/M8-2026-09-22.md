# M8 Benchmark Report — 2026-09-22

Milestone M8e: EVAL/EVALSHA throughput vs Redis 7.2.7
(docs/m8-detailed-plan.md). Ultima runs every script in a FRESH
gopher-lua wasm VM (decision S4: wazero instantiation + stdlib open
per run, no shared state); Redis compiles once and re-runs the
cached function in its shared PUC state. Every row's gap is the
VM-lifecycle cost (~43 ms/run — EVALSHA ≈ EVAL confirms it is
instantiation, not compile); at 1k loop iterations R3 (wazero's
interpreter backend on darwin/arm64) barely registers next to it
and dominates only for CPU-heavy scripts. A per-script VM pool is
the sketched mitigation (docs/m8-detailed-plan.md M8e).

## Environment

- Machine: Apple M4 Max, 14 cores, 36 GB RAM (darwin/arm64)
